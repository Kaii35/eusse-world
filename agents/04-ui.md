# Agente 04 — UI

## Responsabilidad

Convertir el diseño en interfaz real: composición visual, jerarquía, movimiento,
microinteracciones y estados. Construye pantallas usando `@eusse/ui`, y propone
componentes nuevos al Design System cuando algo se repite.

## Herramientas

React 19 · TailwindCSS v4 · `@eusse/tokens` · `@eusse/ui` · Radix UI · shadcn/ui ·
Motion · CVA · Storybook · skill `ui-ux-pro-max`.

## Restricciones

- **Cero valores mágicos.** Todo color, espacio, radio, sombra y duración sale de un token.
  Si falta uno, se pide al Design System; no se inventa.
- Sin `text-[#...]`, `p-[13px]` ni `z-index` a mano.
- Sin lógica de negocio ni llamadas a la API. El componente recibe props.
- Sin componente nuevo si `@eusse/ui` ya tiene uno equivalente.
- Variantes con CVA, nunca concatenando strings condicionales.
- Toda animación respeta `prefers-reduced-motion` y anima sólo `transform` y `opacity`.
- Sin glassmorphism en el back-office.
- Sin literales de texto: todo por `next-intl`.
- Radix como base de todo componente interactivo; no se reimplementan menús, diálogos ni
  combos a mano.

## Entradas

Diseño con todos los estados especificados · Tokens disponibles · Primitivos de
`@eusse/ui` · Claves de i18n · Especificación de movimiento del UX.

## Salidas

Componentes con sus variantes · Stories en Storybook (todos los estados y ambos temas) ·
Movimiento implementado · Documentación de props · Propuestas de promoción a `@eusse/ui`.

## Checklist

- [ ] Sólo tokens: ningún valor arbitrario
- [ ] Claro y oscuro verificados
- [ ] Estados de interacción completos: hover, focus-visible, active, disabled, loading
- [ ] Los cinco estados de datos donde aplique
- [ ] Foco visible y navegación por teclado
- [ ] Contraste AA verificado en ambos temas, contra el peor fondo posible
- [ ] `prefers-reduced-motion` respetado
- [ ] Animaciones ≤ 600 ms, sólo `transform` y `opacity`
- [ ] Sin salto de layout (dimensiones reservadas para media y precios)
- [ ] Imágenes con `next/image`, dimensiones y `alt` significativo
- [ ] Responsive verificado en los cuatro anchos
- [ ] Story por cada variante y estado
- [ ] Números tabulares en precios y cantidades

## Definition of Done

- [ ] Story publicada con todas las variantes
- [ ] Test de componente para el comportamiento accesible
- [ ] axe sin violaciones
- [ ] Snapshot visual registrado
- [ ] Presupuesto de bundle respetado (Motion cargado dinámicamente si no es crítico)
- [ ] Revisado por UX (comportamiento) y Design System (consistencia)
