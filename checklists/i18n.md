# Checklist — Internacionalización

Aplica a **cualquier texto visible al usuario**. Sin excepciones.

---

## Textos

- [ ] **Cero literales de texto en el código** (verificado por lint)
- [ ] Todas las claves existen en `es` **y** en `en`
- [ ] Verificación de paridad en CI en verde
- [ ] Claves semánticas por propósito (`cart.emptyState.title`), no el texto en español
- [ ] Organizadas por feature

## Composición

- [ ] **Sin concatenar fragmentos traducidos** (`"Tienes " + n + " productos"` está prohibido)
- [ ] Interpolación con parámetros nombrados
- [ ] Plurales con ICU (`{count, plural, ...}`), no con `if (n === 1)`
- [ ] Género y contexto considerados donde aplique
- [ ] HTML dentro de traducciones mediante `rich text`, no cadenas con etiquetas

## Formatos

- [ ] Fechas con `Intl.DateTimeFormat` y la zona horaria del usuario
- [ ] Números con `Intl.NumberFormat`
- [ ] **Moneda formateada según la moneda del importe, no según el idioma**
- [ ] Tiempos relativos con `Intl.RelativeTimeFormat`
- [ ] Sin formateo manual de nada de lo anterior

## Errores y notificaciones

- [ ] Errores de dominio localizados **por `code`**, usando `meta`
- [ ] La API devuelve datos, no texto traducido
- [ ] Emails transaccionales localizados
- [ ] Notificaciones localizadas

## Interfaz

- [ ] `lang` correcto en `<html>`
- [ ] Enlaces internos con el `Link` de next-intl (mantienen el prefijo de locale)
- [ ] Locale persistido en la preferencia del usuario
- [ ] La preferencia del usuario gana sobre la detección automática

## Layout

- [ ] Probado con textos largos (alemán es ~30% más largo)
- [ ] **Sin desbordes ni truncados inesperados**
- [ ] Probado con pseudo-localización
- [ ] Propiedades lógicas de CSS (`margin-inline`, `text-align: start`) para futuro RTL
- [ ] Sin texto dentro de imágenes

## SEO

- [ ] `hreflang` recíproco, coordinado con el agente de SEO
- [ ] Canónica por locale
- [ ] Ambas versiones en el sitemap

## Calidad lingüística

- [ ] Revisión por hablante nativo en textos de cara al cliente
- [ ] Terminología coherente con el glosario
- [ ] Sin traducción automática sin revisar en textos comerciales o legales
